Gomrah — Unified Request Management Platform

Previous Next

Gomrah is a Unified Request Management Platform (URMP) developed as a final-year engineering project (PFE) at INSY2S, Lille, France. It centralizes customer requests from multiple channels — email, WhatsApp, web forms — into a single intelligent ticket system with AI-powered analysis, OCR document processing, and automated reply generation.

The platform dramatically reduces manual effort: processing time dropped from ~20 minutes to ~3 seconds (300× faster), with 78% of requests handled automatically, 94.3% OCR accuracy, and a 73% reduction in operational cost per request.

Core Modules

Multi-Source Ingestion normalizes all incoming channels (Email via IMAP/OAuth2, WhatsApp Business API, Web Forms, REST API) into a unified ticket format. The Document OCR module uses a multi-engine pipeline — Tesseract (FR/EN) + EasyOCR (Arabic) — with preprocessing for deskewing, contrast normalization, and structured extraction of invoices, passports (MRZ), and complaints.

The AI Analysis & Response Engine uses a fine-tuned BERT classifier (trained on 5,000+ historical tickets) for 5 categories: Complaint, Invoice, Quote, Technical Support, and HR. High-confidence tickets are auto-processed; low-confidence ones are routed to human agents. An LLM-powered RAG pipeline generates multilingual (AR/FR/EN) reply suggestions via Ollama/Gemma and Google Generative AI, with Qdrant as the vector store.

Technical Stack

Backend: Java 17 / Spring Boot 3.2 / Spring Cloud, Python Flask (OCR), Python FastAPI (LLM), Apache Kafka (async messaging), Spring Cloud Gateway, Eureka service discovery.
Frontend & Mobile: React 19 / TypeScript / Vite / Tailwind CSS (admin dashboard), Flutter (mobile apps for citizens and agents).
AI/ML: Tesseract + EasyOCR, BERT, Ollama/Gemma 2B, Qdrant, Sentence Transformers (multilingual-e5-large), NLP (NER, sentiment analysis).
DevOps: Docker, Kubernetes / Minikube, Jenkins CI/CD, Keycloak IAM, Prometheus + Grafana.
Automation: n8n workflow orchestration (5 production workflows).

  • Omnichannel ingestion — Email, WhatsApp, Web Forms, REST API, all normalized into unified tickets
  • Multi-engine OCR — Tesseract + EasyOCR with 94.3% accuracy across invoices, passports, and complaints
  • BERT classifier — Fine-tuned on 5,000+ tickets for 5-category routing with confidence-based human escalation
  • RAG-powered reply generation — Multilingual (AR/FR/EN) LLM replies via Ollama/Gemma and Google AI
  • n8n workflow automation — 5 production workflows orchestrating AI services and multi-API integrations
  • Hybrid microservices architecture — 12 services (6 domain + 6 cross-cutting) with event-driven Kafka messaging
  • GDPR compliance — AES-256 encrypted storage (MinIO), Elasticsearch full-text search, right to erasure
  • 300× faster processing — ~20 min manual → ~3 sec automated, 78% requests handled without human intervention

BuyMe Microservice

Previous Next

BuyMe is a cutting-edge e-commerce platform built using a microservices architecture to ensure scalability, modularity, and maintainability. The platform leverages advanced technologies to deliver a robust and efficient shopping experience.

Technical Highlights

The system is designed with Spring Boot microservices communicating via REST APIs. Service discovery is powered by Eureka, ensuring that each service can dynamically register and locate other services. Security and authentication are managed using Keycloak, providing role-based access control and OAuth2 authentication flows. Asynchronous communication between services is handled with Apache Kafka, enabling scalable event-driven processing, while Feign clients simplify inter-service REST calls.

The platform includes an AI-driven client segmentation and recommendation system that analyzes customer behavior and preferences to deliver personalized product recommendations, improving engagement and conversion rates.

DevOps & Deployment

Continuous integration and deployment are achieved using Jenkins, while containerization is handled via Docker to ensure consistency across environments and ease of deployment. The system can be deployed on cloud infrastructure with automated build and deployment pipelines, providing high availability and scalability.

  • Microservices architecture for modular, scalable, and maintainable development
  • Eureka service discovery for dynamic registration and location of services
  • Keycloak for secure authentication and role-based access control
  • Kafka for asynchronous event-driven communication between services
  • Feign clients for simplified inter-service REST communication
  • AI-based client segmentation and recommendation to deliver personalized shopping experiences
  • Docker & Jenkins for containerization, CI/CD, and reliable deployment

Ala Dhemtk

Previous Next

Ala Dhemtk is a comprehensive web application built as a monolithic Spring Boot backend with an Angular frontend. The platform is designed to facilitate home services such as cleaning, electrical work, plumbing, and other maintenance jobs. Unlike freelance marketplaces, the workers on the platform are salaried employees of the company, ensuring reliability and professionalism.

Platform Workflow

Clients can browse available services and submit job requests directly through the platform. Once a request is submitted, the administrative dashboard allows the admin to review pending jobs and assign them to the most suitable available worker. This workflow ensures efficient job allocation, reduces delays, and maintains high service quality.

The system is designed for both desktop and mobile responsiveness, providing a smooth experience for clients, workers, and administrators alike.

Technical Highlights

The backend is powered by Spring Boot for robust REST API development, with data stored in a relational database such as MySQL. The frontend is developed in Angular, providing a dynamic and interactive user interface. The admin panel includes features for job management, worker availability tracking, and client request monitoring, all in real-time.

  • Monolithic architecture with Spring Boot backend and Angular frontend
  • Home services focus including cleaning, electrical, plumbing, and general maintenance
  • Salaried workers employed by the company for reliability and quality assurance
  • Client job requests submitted through the platform for easy booking of services
  • Admin job assignment to available workers with real-time tracking of assignments and job status
  • Responsive Angular frontend for smooth experience on desktop and mobile devices
